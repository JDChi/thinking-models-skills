# Thinking Models Skills

Transforming Charlie Munger's mental models into AI-compatible Skills.

## Overview

Charlie Munger, Vice Chairman of Berkshire Hathaway, is renowned for his multidisciplinary approach to decision-making through "Mental Models." By mastering core concepts from various disciplines, one can make better decisions in all aspects of life.

This project implements these mental models as standalone Skills, making them available for AI tools that support the Skill mechanism.

## What Are Mental Models?

Mental models are frameworks for understanding how the world works. They help us:

- Analyze problems from multiple perspectives
- Avoid cognitive biases
- Make better decisions under uncertainty
- Think more clearly and rationally

## Skills Included

Each mental model is implemented as a separate Skill. See the `skills/` directory for available models.

## Usage

Each skill can be invoked using its defined name when used with compatible AI tools.
