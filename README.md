# Thinking Models Skills

Transforming multidisciplinary mental models into AI-compatible Skills, inspired by Charlie Munger's latticework philosophy.

## Overview

Charlie Munger, Vice Chairman of Berkshire Hathaway, advocates for a multidisciplinary approach to decision-making through "Mental Models." He emphasizes that by mastering core concepts from various disciplines, one can make better decisions in all aspects of life. While Munger did not publish an explicit list of 100 models, his philosophy has inspired many practitioners to compile and systematize these frameworks from multiple domains including mathematics, physics, biology, psychology, and economics.

This project implements these foundational thinking frameworks as standalone Skills, making them available for AI tools that support the Skill mechanism.

## What Are Mental Models?

Mental models are frameworks for understanding how the world works. They help us:

- Analyze problems from multiple perspectives
- Avoid cognitive biases
- Make better decisions under uncertainty
- Think more clearly and rationally

## Skills Included

Each mental model is implemented as a separate Skill. See the `skills/` directory for available models.

## Usage

Each skill can be invoked using its defined name when used with compatible AI tools.
